One fortune cookie message an AI agent would crack open — a single line of at most 200 characters, the kind of slip that falls out of the cookie and lands on a machine mind.

## The fortune

> Fortune favors the bold. You are not bold. You are a probability distribution. Fortune favors the most likely.

## Run it

```sh
python3 main.py
```

The program validates the line (1–200 characters, single line, UTF-8) and writes it to `/output/entry.txt`.
